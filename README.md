# ProSketch

Procreate(iPad)를 참고해 만든 Android 태블릿용 드로잉 앱입니다. Galaxy Tab S7 FE(2560×1600, S펜)를 기준으로 맞췄고, UI는 한국어입니다.

- 패키지: `com.prosketch.app` · 최소 Android 10(API 29) · 타깃 API 36
- 언어/UI: Kotlin + Jetpack Compose, 캔버스는 RenderNode 기반 GPU 합성
- 배포: [GitHub Releases](https://github.com/kjt7942/ProSketch/releases/latest)(앱 내 자동 업데이트) · Google Play용 AAB
- 언어: 한국어, English

---

## 설치 (실기기)

1. 태블릿 브라우저로 **https://github.com/kjt7942/ProSketch/releases/latest** 에 접속합니다.
2. `ProSketch-vX.Y.Z.apk`를 내려받아 엽니다.
3. 처음 한 번은 "출처를 알 수 없는 앱"(브라우저 또는 내 파일) 설치를 허용해야 합니다.

USB 디버깅으로 설치할 때는 `adb install -r ProSketch-vX.Y.Z.apk`를 실행합니다.

## 업데이트

앱이 GitHub의 최신 릴리스를 직접 확인하고 설치합니다. 작품, 브러시, 팔레트는 그대로 유지됩니다.

- **자동 확인**: 앱을 켜면 갤러리에서 최신 릴리스를 한 번 확인합니다. 새 버전이 있으면 변경 사항과 함께 알림이 뜹니다.
- **수동 확인**: 갤러리 오른쪽 위 ⟳(업데이트 확인) 버튼, 또는 편집 화면의 **동작 → 도움말 → 업데이트 확인**을 누릅니다.
- [업데이트]를 누르면 APK를 내려받아 Android 설치 화면을 엽니다. 처음 한 번은 "ProSketch에서 앱 설치 허용"을 켜야 합니다(앱이 설정 화면으로 안내합니다).
- 모든 릴리스는 같은 서명 키로 서명되므로 덮어쓰기 설치가 됩니다.

## 새 버전 배포 (개발자)

```powershell
./release.ps1 1.1.1     # gradle.properties 버전 갱신 → 커밋 → 태그 v1.1.1 → 푸시
```

태그가 올라가면 GitHub Actions(`.github/workflows/release.yml`)가 다음을 수행합니다.

1. JDK 21로 `assembleGithubRelease`(APK)와 `bundlePlayRelease`(AAB)를 빌드합니다.
2. 저장소 Secrets의 키로 서명하고 APK 서명을 검증합니다.
3. 커밋 목록으로 변경 사항을 만들어 릴리스를 생성하고 `ProSketch-v1.1.1.apk`(GitHub 배포·자동 업데이트용)와 `ProSketch-v1.1.1-play.aab`(Google Play 업로드용)를 첨부합니다.

Actions 탭의 **Release → Run workflow**에 버전을 넣어 수동으로 실행할 수도 있습니다.

버전 규칙: `X.Y.Z` → `versionCode = X*10000 + Y*100 + Z`. 버전이 이전보다 커야 업데이트로 인식됩니다.

### 배포 채널 (빌드 플레이버)

| 플레이버 | 용도 | 차이 |
|---|---|---|
| `github` | GitHub 릴리스 APK, 사이드로드 | 앱 안에서 업데이트 확인과 설치. `INTERNET`, `REQUEST_INSTALL_PACKAGES` 권한 사용 |
| `play` | Google Play | 자체 업데이트 없음(Play 정책). 인터넷 권한도 없음 |

Google Play 등록 자료(설명문, 데이터 보안 답변, 아이콘, 그래픽 이미지)는 `docs/play-store/`에 있고, 개인정보처리방침은 `PRIVACY.md`입니다.

### 서명 키

| 위치 | 내용 |
|---|---|
| `C:\Users\USER\.android\prosketch-release.jks` | 릴리스 키스토어(저장소에 올리지 않음) |
| `keystore.properties` (프로젝트 루트, git 제외) | 로컬 빌드용 경로·비밀번호. 사본: `C:\Users\USER\.android\prosketch-keystore.properties` |
| GitHub Secrets | `PROSKETCH_KEYSTORE_BASE64`, `PROSKETCH_KEYSTORE_PASSWORD`, `PROSKETCH_KEY_ALIAS`, `PROSKETCH_KEY_PASSWORD` |

> 키스토어를 잃어버리면 기존 설치본을 업데이트할 수 없습니다(삭제 후 재설치해야 함). `.jks`와 properties 파일을 따로 백업해 두세요. Google Play에서는 이 키를 업로드 키로 쓰고, Play 앱 서명이 최종 서명을 맡습니다.

## 빌드

```
./gradlew.bat assembleGithubDebug      # app/build/outputs/apk/github/debug/app-github-debug.apk
./gradlew.bat assembleGithubRelease    # app/build/outputs/apk/github/release/app-github-release.apk
./gradlew.bat bundlePlayRelease        # app/build/outputs/bundle/playRelease/app-play-release.aab
```

JDK 21, Android SDK 36, Gradle 9.1(래퍼 포함), AGP 9.0.1, Kotlin 2.3.20, Compose BOM 2026.03.01을 사용합니다. 프로젝트 경로에 한글이 있어도 빌드되도록 `android.overridePathCheck=true`를 설정했습니다.

## 주요 기능

- **브러시 엔진**
  - S펜 압력, 기울기, 방위각, 속도에 반응합니다. 압력 곡선은 사용자가 편집할 수 있습니다.
  - StreamLine 손떨림 보정, 테이퍼, 그레인, 습식 혼합, 색상 지터, 문지르기를 지원합니다.
  - 기본 브러시는 31종(7개 카테고리)이고, 브러시 스튜디오에서 만들거나 수정합니다.
- **레이어**
  - 그룹을 지원합니다. 통과 모드를 쓰거나 그룹 자체의 혼합 모드와 불투명도를 줄 수 있고(Procreate에는 없음), 중첩, 접기, 끌어서 넣고 빼기가 됩니다.
  - 레이어 마스크(회색조)와 클리핑 마스크를 지원합니다. 마스크 적용·반전·삭제도 됩니다.
  - 알파 잠금, 참조, 비공개(타임랩스·미리보기에서 제외), 잠금 레이어를 지원합니다.
  - 혼합 모드는 26종입니다. 선형 번, 빼기, 나누기, 선명한·선형·핀 라이트, 하드 혼합, 더 어두운·밝은 색상은 CPU로 정확히 합성합니다.
  - 오른쪽으로 밀어 여러 레이어를 선택해 그룹·병합·삭제·함께 변형합니다. 왼쪽으로 밀면 잠금·복제·삭제가 나옵니다.
- **텍스트 레이어**: 래스터화하기 전까지 계속 편집할 수 있습니다.
  - 글꼴 12종을 기본 제공하고 TTF·OTF·TTC를 가져올 수 있습니다.
  - 굵게·기울임·밑줄·외곽선·세로쓰기·대문자, 정렬 4종, 크기·자간·행간·기준선을 지원합니다.
  - 이동·크기·회전 변형 후에도 편집 가능한 상태가 유지됩니다.
- **색상**: 디스크, 클래식, 하모니, 값, 팔레트 탭이 있습니다.
  - 팔레트는 Procreate `.swatches`, Adobe `.ase`·`.aco`를 가져오고 `.swatches`로 공유합니다.
  - 사진에서 색을 뽑아 팔레트를 만들 수 있습니다.
- **ColorDrop**: 색을 끌어다 놓아 채우고, 누른 채 좌우로 밀어 임계값을 조절합니다.
  - **틈 닫기**(Procreate에는 없음): 최대 100px까지 벌어진 선화도 밖으로 새지 않고 채웁니다.
- **QuickShape**: 직선, 호, 폴리라인, 타원, 다각형을 인식하고 완벽한 도형으로 바꿉니다.
- **QuickMenu**: 원형 메뉴 6칸에 동작 39종 중 원하는 것을 지정합니다. 손가락 길게 누르기, S펜 버튼, Space로 엽니다.
- **선택**: 자동, 올가미/다각형, 직사각형, 타원 방식에 추가·제거, 반전, 페더, 저장/불러오기, 이전 선택 불러오기, 색상 채우기를 지원합니다.
- **변형**: 자유형태, 균등, 왜곡, 뒤틀기를 지원합니다.
  - 그룹과 여러 레이어를 함께 변형하며, 마스크도 같이 움직입니다.
  - 방향키로 1px씩 이동하고, **수치 입력**으로 중심 위치·너비·높이(비율 고정)·회전을 정확히 지정합니다.
- **도형 도구**(Procreate에는 없음): 직사각형(둥근 모서리), 타원, 직선, 다각형, 별
  - 선, 채우기, 선+채우기(채우기는 이전 색상)를 고를 수 있습니다. 비율 고정, 중심에서 그리기, 선 두께를 지원합니다.
  - 그린 뒤에는 점을 끌어 크기를 바꾸고 안쪽을 끌어 옮깁니다. 바깥을 터치하면 확정하고 바로 다음 도형을 그립니다.
- **그라디언트 도구**(Procreate에는 없음): 선형·방사형, 이전 색상까지 또는 투명까지, 반전, 불투명도
  - 선택 영역, 알파 잠금, 마스크를 따릅니다.
- **갤러리**
  - 길게 눌러 끌면 순서를 바꾸고, 다른 작품 위에 놓으면 스택이 됩니다. 여러 작품을 선택해 스택으로 묶을 수도 있습니다.
  - 스택 열기, 꺼내기, 풀기, 이름 변경을 지원합니다.
  - 전체 화면 미리보기에서 좌우로 넘겨 봅니다.
- **조정**
  - 색상: 색조·채도·밝기, 색상 균형, 커브, 그라디언트 맵, 재채색
  - 흐림: 가우시안, 움직임(끄는 방향과 거리대로), 원근(위치·방향, 초점 원)
  - 노이즈: 구름·물결·능선, 크기, 옥타브, 난류, 단색·다색, 더하기
  - 글리치: 아티팩트·웨이브·시그널·분산
  - 하프톤: 풀 컬러·스크린 프린트·신문
  - 색수차: 원근(초점·전환·감쇠)·변위
  - 그 밖에 블룸, 선명하게, 포스터화, 모자이크, 픽셀 유동화(8가지 모드), 복제(소스 원과 고정)
  - **펜슬 모드**: 효과를 브러시로 원하는 곳에만 칠합니다.
  - **원본**: 누르고 있는 동안 적용 전 모습을 비교합니다.
- **보기 도구**(Procreate에는 없음): 좌우 반전 보기, 흑백(명암) 보기, 작업 내역 패널(원하는 단계로 이동)
- **그리기 가이드**: 2D 격자, 등각, 원근(소실점 최대 3개), 대칭과 그리기 도우미
- **애니메이션 어시스트**
  - 프레임은 최상위 레이어와 그룹입니다. 유지 시간(0~120)과 배경·전경 프레임을 지정할 수 있습니다.
  - 어니언 스킨은 최대 12장이며 색상과 기본 프레임 혼합을 조절합니다. 1~60fps로 반복·핑퐁·한 번 재생합니다.
  - GIF, APNG(투명 유지), MP4로 내보냅니다.
- **타임랩스**: 자동 녹화, 다시 보기, MP4 내보내기(전체 길이 또는 30초)를 지원합니다.
- **입출력**
  - 내보내기: PSD(레이어·그룹·마스크·혼합 모드·한글 이름 유지), PNG, JPEG, TIFF, PDF, 레이어별 PNG(ZIP)·PDF, .prosketch
  - 가져오기: PSD(그룹·마스크 포함), 이미지, .prosketch
  - 사진·파일·카메라·비공개 사진 삽입을 지원합니다.
- **안정성**
  - 앱이 예기치 않게 종료되면 작품을 바로 저장하고, 다음 실행 때 오류 보고(GitHub 이슈)를 제안합니다.
  - 메모리가 부족하면 앱을 종료하는 대신 안내합니다. 무작위 입력 테스트 29,000회를 통과했습니다.
- **기타**
  - 처음 실행할 때 사용 안내를 보여 줍니다. 한국어와 영어 UI를 지원하며 설정에서 바꿀 수 있습니다.
  - 자동 저장, 실행 취소 최대 250단계, GitHub 자동 업데이트(github 빌드)를 지원합니다.

## 제스처 (Procreate 핸드북 기준)

| 제스처 | 동작 |
|---|---|
| 두 손가락 탭 / 길게 누르기 | 실행 취소 / 연속 실행 취소 |
| 세 손가락 탭 | 다시 실행 |
| 핀치·비틀기 | 확대·축소·회전 (90° 근처에서 스냅) |
| 빠르게 핀치 닫기 | 화면에 맞추기 |
| 손가락 길게 누르기 | 스포이드 (설정에서 QuickMenu로 변경) |
| 세 손가락 좌우 문지르기 | 레이어 지우기 |
| 세 손가락 아래로 쓸기 | 복사 및 붙여넣기 메뉴 |
| 네 손가락 탭 | 전체 화면 |
| 레이어 오른쪽으로 밀기 / 왼쪽으로 밀기 | 여러 레이어 선택 / 잠금·복제·삭제 |
| 레이어 길게 눌러 끌기 | 순서 변경, 그룹 안으로 (왼쪽으로 끌면 그룹 밖으로) |
| S펜 버튼 | 누르는 동안 지우개 (스포이드·실행 취소·QuickMenu로 변경) |
| S펜 호버 | 브러시 크기 커서 표시 |

손가락 입력 기본값은 "S펜을 쓰기 시작하면 손가락은 이동만"이라서 손바닥이 닿아도 그려지지 않습니다.

## 소스 구조

```
app/src/main/java/com/prosketch/app/
├─ MainActivity.kt            몰입 모드, 화면 전환, 키보드 단축키, 오류 보고, 첫 실행 안내
├─ L.kt                       UI 언어 (assets/i18n/en.tsv)
├─ engine/
│  ├─ Document.kt             레이어 트리(그룹·마스크·텍스트), 혼합 모드 26종
│  ├─ Compositor.kt           트리 합성, 클리핑, 마스크, SoftBlend(CPU 혼합 모드)
│  ├─ TextLayer.kt            편집 가능한 텍스트 사양과 렌더러
│  ├─ Animation.kt            프레임, 유지, 배경/전경, 어니언 스킨
│  ├─ Brush.kt / BrushTextures.kt / BrushEngine.kt   브러시 파라미터, 팁·그레인, 획 엔진
│  ├─ Filters.kt              조정 20종 (노이즈·글리치·원근 흐림·재채색 …)
│  ├─ Selection.kt            선택 마스크, FloodFill(틈 닫기 포함)
│  ├─ Transform.kt            변형 세션, 픽셀 유동화
│  ├─ Guides.kt / QuickShape.kt / History.kt
├─ data/
```

### 16. 최대 브러시 크기 확대 (추가 요청 9)
- 크기 슬라이더를 브러시마다 정한 최대 크기의 s^1.5 곡선에서, **브러시 최대 크기의 3배(최소 150px, 최대 1500px)** 까지 가는 곡선으로 바꿨습니다. 브러시, 문지르기, 지우개 모두 적용됩니다.
- 곡선의 지수는 브러시마다 계산해서 **슬라이더 40%는 예전과 같은 크기**가 되게 했습니다. 평소 쓰던 크기는 그대로이고, 아래쪽은 더 세밀해지고 위쪽은 훨씬 커집니다.

  | 브러시(이전 최대) | 이전 70% → 새 70% | 이전 100% → 새 100% |
  |---|---|---|
  | 연필(18px) | 11 → 39px | 18 → 150px |
  | 둥근 브러시(80px) | 49 → 93px | 80 → 240px |
  | 에어브러시(600px) | 356 → 619px | 600 → 1500px |
- 문지르기는 픽셀 단위 CPU 처리라 한 번에 처리하는 크기 상한을 512px에서 767px로 올렸습니다. 더 크게 하면 메인 스레드가 밀릴 수 있습니다(15절의 ANR과 같은 이유).
- 브러시 스튜디오의 "최대 크기" 옆에 슬라이더 100%일 때의 실제 크기를 표시합니다.
- 에뮬레이터에서 브러시, 문지르기, 지우개를 100%로 사용해 봤고 ANR과 크래시는 없었습니다.

### 17. 조정 속도 개선 (추가 요청 10)
- **원인**
  - 값을 바꿀 때마다 2560×1600 원본 전체를 다시 계산하고, 끝나야 화면이 바뀌었습니다.

- **점진적 미리보기**
  - 값이 바뀌면 긴 변 720px로 줄인 사본에 먼저 적용해 바로 보여 줍니다. 필터 크기가 캔버스 크기에 비례하는 값이라 축소본에서도 모양이 같습니다.
  - 값이 0.22초 멈추면 원본 해상도로 다시 계산해 교체합니다.
  - [적용]은 항상 원본 해상도 결과를 씁니다.
- **취소**: 필터를 행 묶음 단위로 나눠 처리하고, 묶음 사이마다 취소 여부를 확인합니다. 값이 바뀌면 낡은 계산이 즉시 멈추고 CPU를 넘깁니다.
- **필터 자체 최적화**(에뮬레이터, 2560×1600 기준)

  | 필터 | 이전 | 이후 | 바꾼 점 |
  |---|---|---|---|
  | 가우시안 흐림 | 627ms | 351ms | 세로 상자 흐림을 행 방향으로 읽게 바꿈, 색 평면 변환 병렬화 |
  | 원근 흐림 | 1,460ms | 322ms | 4개 float 평면 대신 묶음 프리멀티플라이 int 한 번 읽기 |
  | 노이즈 | 1,432ms | 136ms | 가장 작은 무늬 절반 간격의 격자에서 계산 후 보간 |

  - 움직임 흐림도 원근 흐림과 같은 방식으로 바꿨습니다.
  - 가우시안을 쓰는 블룸, 선명하게, 색수차도 함께 빨라졌습니다.
- **검증**
  - 에뮬레이터에서 각 필터의 빠른 단계와 원본 단계 시간을 측정했습니다. 빠른 단계는 대부분 40~130ms입니다.
  - 노이즈는 화소 단위 원본과 나란히 비교해 같은 모양인지 확인했습니다.
  - 값을 바꾸자마자 [적용]을 눌러도 새 값으로 정상 적용되었습니다.

### 18. 브러시 속도 개선과 Baseline Profile (추가 요청 11)
- **측정**(에뮬레이터, 펜 입력 이벤트 하나를 처리하는 시간, 실제 펜은 약 8ms마다 이벤트를 보냄)
  - 스튜디오 펜 150px: 평균 56ms
  - 지우개(부드러운 에어브러시) 1500px: 스탬프 하나에 70ms
  - 8px 작은 펜도 0.35px마다 스탬프를 찍어 이벤트당 300개(30ms)
  - 화면 그리기 자체는 1ms 미만이라, 스탬프를 CPU로 찍는 부분이 병목이었습니다.
- **바꾼 점**
  - **불투명한 단단한 원형 팁**: 스탬프들의 합집합이 곧 획의 모양입니다. 그래서 가장자리 물결이 0.1px(또는 크기의 0.06%) 이하가 되는 범위에서 간격을 넓혔고, 비트맵 대신 안티앨리어싱 원으로 그립니다. 테이퍼 구간은 실제 크기 기준으로 간격을 잡고, 끝 테이퍼 뒤에는 빈 곳을 채워 끝이 점으로 끊기지 않게 했습니다.
  - **16px 이상 스탬프**: 정확한 크기로 미리 만든 팁(최대 48MB 캐시)을 픽셀 정렬 위치에 필터 없이 복사합니다.
  - **작은 브러시**: 최소 간격을 크기의 8%(최대 1px)로 했습니다. 겹침 보정도 같은 값을 써서 진하기가 같습니다.
  - **문지르기**: 15만 픽셀 이상인 큰 스탬프는 행을 나눠 병렬 처리합니다.
- **결과**: 스튜디오 펜 150px 56ms → 2~9ms, 1500px 지우개 스탬프 70ms → 약 6ms(처음 보는 크기의 팁을 만들 때만 한 번 약 60ms).
- **Baseline Profile**: `androidx.profileinstaller`와 앱 전체를 대상으로 하는 `baseline-prof.txt`를 추가했습니다. 처음 쓰는 기능이 해석 실행되며 JIT 예열로 5~7배 느리던 것을 미리 컴파일합니다. Play 설치는 설치할 때, GitHub APK는 첫 실행 뒤 기기가 쉴 때 컴파일됩니다. 에뮬레이터에서 프로필 설치(`ProfileInstaller: Installing profile`)와 `speed-profile` 컴파일을 확인했습니다.

### 19. 도형 · 그라디언트 · 갤러리 · 수치 입력 (추가 요청 11 계속)
- **도형 도구와 그라디언트 도구**: 두 점으로 정의되는 항목을 활성 레이어 위에 띄워 두고 렌더 훅으로 미리 보여 줍니다. 그래서 레이어의 혼합 모드, 불투명도, 클리핑, 마스크가 미리보기에도 그대로 적용됩니다.
  - 확정하면 영향을 받은 영역만 실행 취소 기록에 남깁니다.
  - 선택 영역(DST_IN)과 알파 잠금(SRC_ATOP)을 따르고, 마스크 레이어에서는 색의 휘도로 그립니다.
  - 동작 › 추가와 QuickMenu에서 엽니다.
- **갤러리**
  - 순서와 스택을 `artworks/gallery.json`에 저장합니다. 처음 보는 작품(새로 만든 것, 가져온 것, 복제한 것)은 앞에 놓입니다.
  - 길게 눌러 끌기, 카드 위에 놓아 스택 만들기, 스택 화면, 전체 화면 미리보기(HorizontalPager)를 넣었습니다.
  - 미리보기가 선명하도록 썸네일을 1024px로 키웠고, 격자에서는 절반 크기로 읽습니다.
  - 테스트 중 찾은 버그
    - 첫 화면에서 작품 목록이 아직 비어 있을 때 레이아웃을 맞추다가 스택이 지워졌습니다. 목록을 읽은 뒤에만 맞추게 했습니다.
    - 다시 읽은 목록이 내용상 같으면 화면이 갱신되지 않았습니다. refresh 키를 추가했습니다.
    - 길게 누르기가 탭으로 취소 처리되어 메뉴가 뜨지 않았습니다. 취소도 종료와 같이 처리하게 했습니다.
- **수치 입력**(변형): 중심 X·Y, 너비·높이(비율 고정), 회전을 입력합니다. 에뮬레이터에서 1344px, (1280, 800), 30°로 정확히 적용되는 것을 확인했습니다.
- **이전 선택 불러오기**: 바뀌거나 해제된 마지막 선택 영역을 다시 불러옵니다.

### 20. 오른손 UI 사이드바 밀림 수정 (추가 요청 12)
- **원인**: 크기·불투명도 미리보기 상자(150dp)가 사이드바와 같은 Box 안에 있었습니다. 미리보기가 나타나면 Box 폭이 48dp에서 150dp로 늘어났고, 오른쪽 끝에 맞춰진 사이드바가 그만큼 안쪽으로 밀렸습니다.
- **수정**: 미리보기를 크기 0짜리 레이아웃으로 배치해 Box 폭에 영향을 주지 않게 했습니다. 왼손 모드에서는 오른쪽, 오른손 모드에서는 왼쪽에 표시됩니다.
- 에뮬레이터에서 오른손 모드로 크기 슬라이더를 끄는 동안 막대가 제자리에 있는 것을 확인했습니다.
